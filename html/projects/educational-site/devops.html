Introduction

DevOps is a combination of development and operations practices.

It focuses on improving collaboration between developers and system administrators.

DevOps helps teams build, test, deploy, and maintain software faster and more reliably.

Git

Git is a version control system used to track changes in software projects.

Developers use Git to manage code history, create branches, and collaborate with other developers. 


                git init

                git add .

                git commit -m "message"

                git push

GitHub

GitHub is an online platform for storing Git repositories.

It provides collaboration features such as pull requests, issues, and project management tools.

Docker

Docker is a containerization platform that packages applications with all required dependencies.

Containers make applications easier to run consistently across different environments. 


                docker build -t app .

                docker run app

Linux

Linux is widely used for servers because it is stable, secure, and flexible.

Many cloud servers run Linux operating systems.

Automation

Automation reduces manual work by using scripts and tools.

Common DevOps automation tools include GitHub Actions, Jenkins, and Ansible.

DevOps Workflow

  • Write Code
  • Commit Changes
  • Run Automated Tests
  • Build Application
  • Deploy Application
  • Monitor Performance
