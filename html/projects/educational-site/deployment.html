Introduction

Deployment is the process of making an application available for users on the internet.

After developing a website or application, developers deploy it to servers or cloud platforms.

Deployment involves server setup, configuration, security, domain management, and continuous delivery.

Hosting

Hosting means storing application files on a server so users can access them online.

Different types of hosting include shared hosting, virtual private servers, and cloud hosting.

  • Shared Hosting
  • Virtual Private Server (VPS)
  • Cloud Hosting

Cloud Platforms

Cloud platforms provide servers, storage, databases, and networking services required for modern applications.

  • AWS (Amazon Web Services)
  • Microsoft Azure
  • Google Cloud Platform

AWS Overview

AWS is one of the most popular cloud platforms used for deploying web applications.

Common AWS services include EC2 for servers, S3 for storage, and RDS for databases. 


                EC2  - Virtual Server
                S3   - File Storage
                RDS  - Managed Database

CI/CD

CI/CD stands for Continuous Integration and Continuous Deployment.

It automates testing and deployment processes, allowing developers to release updates faster and more safely.

Environment Variables

Environment variables store configuration values such as database passwords, API keys, and secret information.

They keep sensitive information separate from application code. 


                DATABASE_URL=localhost
                SECRET_KEY=mysecret
