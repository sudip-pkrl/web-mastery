Introduction

Databases are used to store, organize, and manage application data.

Backend applications use databases to save user information, products, transactions, and other important data.

SQL Databases

SQL databases store data in tables using rows and columns.

Examples include PostgreSQL, MySQL, and SQLite. 

                CREATE TABLE users (
                id INT,
                name VARCHAR(50)
                );

PostgreSQL

PostgreSQL is a powerful open-source relational database system.

It supports advanced features like indexing, transactions, and complex queries.
