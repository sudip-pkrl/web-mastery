Introduction

Frontend development focuses on creating the user interface and user experience of websites and applications.

It involves designing layouts, adding styles, and creating interactive features that users directly interact with.

The main technologies used in frontend development are HTML, CSS, JavaScript, and modern frameworks like React.

HTML

HTML (HyperText Markup Language) is the foundation of every webpage.

It defines the structure of a website using elements like headings, paragraphs, links, images, and forms. 

                <h1>Hello World</h1>
                <p>Welcome to frontend development</p>

CSS

CSS (Cascading Style Sheets) is used to design and style HTML elements.

It controls colors, layouts, spacing, animations, and responsive designs. 

                body {
                    background-color: lightblue;
                    font-family: Arial;
                }

JavaScript

JavaScript adds behavior and interactivity to websites.

It allows developers to create dynamic content, handle events, and communicate with servers. 

                document.write("Hello JavaScript");

React Overview

React is a JavaScript library used for building fast and reusable user interfaces.

It uses components to create modern single-page applications.
